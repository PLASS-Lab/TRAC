# Manuscript → code map

Every claim of the manuscript that rests on computation is listed with the
module that produces it, the command to run, the record in `validation/` and
the value to compare. Numbering follows the main text and Supplementary
Materials. Formal statements and proofs are established in the manuscript;
the programs check finite constants, boundary cases and the reported
numbers. They do not certify a continuous supremum.

Commands are run from the repository root with
`E=paper/mdpi_math_v4/supplementary`, the frozen evidence directory cited in
Supplementary Section S6. The Kodak and depth replays need the dataset cases,
which are not distributed: rebuild them first with `python -m tworead.cases
build` (README, section *Datasets*). `python -m tworead.cases verify` runs both
replays and should print [`validation/cases.json`](../validation/cases.json).

the third column with the same arguments (`scripts/replay_math_v3_5.py`
defaults to the in-repository `evidence_v3_5/`). The original programs are
archived inside the evidence directories (`code/` or `scripts/`) where
available.
